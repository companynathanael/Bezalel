# Prompt de aparência — Bezalel

Prompt usado para gerar a aparência (site/painel) do Bezalel, no mesmo padrão visual do Asafe e do Gather.

```
Crie apenas a APARÊNCIA (site/painel em HTML, CSS e JS, sem back-end) do BEZALEL, o 3º motor da Nathanael Industries.

PADRÃO VISUAL
- Siga exatamente o mesmo padrão de aparência do Asafe (repositório companynathanael/Asafe, index.html) e do Gather: mesma estrutura de layout, menu, cards, tipografia, espaçamentos e componentes.
- Mude somente as cores e o conteúdo.
- Cores: PRETO e VERDE (sugestão: fundo #0A0A0A, verde principal #22C55E, verde escuro #15803D, texto #F5F5F5).
- Logo: bigorna branca sobre fundo preto (arquivo identidade/logos/bezalel.jpg do repositório companynathanael/NATHANAEL-INDUSTRIES).
- Use dados de demonstração (mock); nada precisa funcionar de verdade ainda.

QUEM É O BEZALEL
Motor criador de IAs. O nome vem de Bezalel, o artesão escolhido para construir o tabernáculo (Êxodo 31).
A bigorna é onde ele dá forma às IAs.
Linha de produção: Gather (APIs) → Fornalha (funde e prova) → BEZALEL (molda a IA) → IA pronta. O Asafe sustenta tudo.

FUNÇÕES (cada uma vira uma tela/aba)
1. Painel geral: IAs em construção, IAs ativas, próximas versões, alertas.
2. Bigorna (oficina): IAs em construção com as etapas Definição → Montagem → Prova de fogo (na Fornalha) → Liberada.
3. Definição de IA: ficha de cada IA com propósito, personalidade, regras, permissões (do Asafe) e habilidades (vindas da Fornalha).
4. Catálogo de IAs: IAs criadas, com versão e status. Exemplos: Horácio HoV 1.1 (assistente pessoal do Sr. Nathanael) e Miquéias JpG 1.0 (tarefas, cálculos e trading), ambos "em construção".
5. Versões e aposentadoria: histórico de versões de cada IA (ex.: HoV 1.1 → 1.2) e IAs aposentadas.
6. Submotores (ainda não produzidos, mostrar como "em breve"): Baluarte (Continuidade), Baú (Memória), Bússola (Autonomia).

NÃO FAZ: testes e avaliação (isso é da Fornalha, na prova de fogo); criar APIs (isso é do Gather).
Textos em português.
```
